## 1. Repository

Use the special profile repository:

`shayangonchoudhury-svg`

The repository must be public and the repository name must match the GitHub username.

## 2. Upload

Upload:

- `README.md`
- `assets/hero.svg`
- `assets/holographic-avatar.png`
- `assets/contribution-art.svg`

## 3. Personalize

Before publishing, replace:

- `https://www.linkedin.com/` with your real LinkedIn profile.
- Any project descriptions/links you want to make more specific.
- The featured-build section if you want different repositories highlighted.

## 4. What makes it match the reel

The layout is designed around the same visual language:

- dark developer dashboard aesthetic
- neon cyan / violet accents
- holographic profile portrait
- GitHub stats
- contribution/activity visualization
- project cards
- terminal-style system panel
- large branded footer
- compact sections that read like a developer portfolio rather than a plain README
